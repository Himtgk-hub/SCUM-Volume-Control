# SCUM Volume Control · HIMTGK

Утилита для Windows: управляйте громкостью SCUM горячими клавишами и автоматически приглушайте резкие и постоянные звуки.

## Скачать и запустить

1. Откройте раздел **Releases** этого репозитория.
2. Скачайте `SCUMVolumeControl-1.0.0-windows-x64.zip` и распакуйте его.
3. Запустите `SCUMVolumeControl.exe`. Установка Python не нужна.

Требуется **64-битная Windows 10/11**. EXE не имеет цифровой подписи, поэтому Windows SmartScreen может показать предупреждение. Проверяйте источник загрузки и контрольную сумму; не отключайте защиту Windows ради программы.

## Возможности

- Управление громкостью приложения через микшер Windows без изменения общей громкости системы.
- Настраиваемые глобальные горячие клавиши и шаг изменения громкости.
- Автоприглушение резких пиков, длительного шума и повторяющихся ударов.
- Независимые выключатели горячих клавиш и автозвука.
- Уведомления Windows или оверлей, работа в системном трее.
- Русский интерфейс, автоматическое сохранение настроек.

## Быстрый старт

1. Запустите SCUM и дождитесь появления звука игры.
2. Проверьте имя процесса в программе: по умолчанию `SCUM`.
3. Задайте ручную громкость. По умолчанию **↑** увеличивает её, **↓** уменьшает, шаг — **5 %**.
4. На вкладке **«Автозвук»** включите общий выключатель: при первом запуске автоматика выключена.
5. Для транспорта используйте поле **«Оставлять от ручной громкости»**. Меньше число — тише. Параметры обнаружения менять необязательно.

Ручная громкость задаёт верхний предел. Например, при ручных 80 % и доле шума 25 % после обнаружения шума микшер ограничивается 20 %. Общий минимум ограничивает снижение: по умолчанию он равен 25 % ручной громкости.

Кнопка закрытия по умолчанию сворачивает программу в трей. Для завершения выберите **выход** в меню значка. При обычном выходе или выключении автозвука утилита восстанавливает ручную громкость; принудительное завершение этого не гарантирует.

## Важные ограничения

- Это реактивное управление микшером, **не аудиолимитер и не средство защиты слуха**. Первый выстрел или удар может прозвучать громко до реакции программы.
- Нет внедрения в процесс игры и обработки аудиопотока. Программа не распознаёт машины, топор или оружие: используются эвристики огибающей уровня.
- Повторяющиеся выстрелы и звуки контейнеров тоже могут включать удержание. Его можно отключить отдельно.
- В эксклюзивном полноэкранном режиме оверлей может быть невидим. Уведомления Windows также зависят от настроек системы и режима «Не беспокоить».
- Не связано с разработчиками SCUM; совместимость с каждой версией игры не гарантируется.

## Настройки и приватность

Настройки и рабочие логи хранятся в `%APPDATA%\SCUMVolumeControl` и не входят в релиз.

Диагностика скрыта за кнопкой **«Настройки → Диагностика…»**. Микрофон включается только после явного нажатия **«Начать отладку»**. Распознавание речи работает локально через Vosk; при первом использовании загружается русская модель. Сохраняются распознанный текст и уровни, не исходная аудиозапись. Перед отправкой логов удалите личную информацию. Переход по ссылкам автора открывает внешний браузер.

## Сборка из исходников

Нужен Python **3.12 x64** под Windows. Запустите из папки проекта:

```bat
build.bat
```

Скрипт создаёт `.venv`, устанавливает зависимости и PyInstaller, собирает `dist\SCUMVolumeControl.exe`.

Для запуска исходников после установки зависимостей:

```powershell
.\.venv\Scripts\python.exe src\main.py
```

Тесты:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests
```

Зависимости: [requirements.txt](requirements.txt). Встраиваемые ресурсы, включая логотип, находятся в `resources`. Программа использует PySide6/Qt, Windows Core Audio через pycaw и локальную модель Vosk для необязательной диагностики.
