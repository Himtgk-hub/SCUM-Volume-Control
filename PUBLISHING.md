# Публикация на GitHub

Подготовленные архивы находятся в `release` после запуска `tools\prepare_release.ps1`.
Ничего не отправляется в интернет автоматически.

## 1. Создайте репозиторий

Откройте https://github.com/new, выберите название `SCUM-Volume-Control` и нужную видимость.
Не добавляйте автоматически README, .gitignore или лицензию: первые два уже подготовлены, а лицензию ещё нужно выбрать.

## 2. Загрузите код

Самый простой способ — GitHub Desktop:

1. Установите приложение с https://desktop.github.com и войдите в свой аккаунт.
2. Используйте **File → New repository**, задайте имя и отдельную пустую папку вне текущего проекта.
3. Распакуйте содержимое `release\SCUMVolumeControl-1.0.0-source.zip` прямо в эту папку (без дополнительного уровня вложенности).
4. Во вкладке Changes проверьте файлы. Там не должно быть EXE, `.venv`, логов, расшифровок речи, `build`, `dist`, `backups` или личного `config.json`.
5. Сделайте commit `Initial release preparation`.
6. Нажмите **Publish repository**, проверьте видимость. Если репозиторий уже создан на сайте, вместо New repository клонируйте его через **File → Clone repository**, затем выполните шаги 3–5 и **Push origin**.

Чистый архив собран по явному списку разрешённых файлов, а не копированием всей рабочей папки.
`.gitignore` защищает от случайного добавления локальных файлов, но не удаляет уже опубликованные данные из истории Git.

## 3. Проверьте перед публичным релизом

- Выберите условия распространения собственного кода. Если нужна MIT или другая открытая лицензия, сначала явно подтвердите выбор и добавьте её текст. Сейчас открытая лицензия не назначена.
- Проверьте лицензии зависимостей и комплект уведомлений в ZIP. Наличие исходников само по себе не решает все лицензионные обязательства Qt/PySide6.
- Проверьте EXE на чистой Windows: запуск без Python, управление SCUM, выключение автоматики, ссылки автора, выход из трея.
- Подготовьте скриншот интерфейса без личной информации. Старый `ui-review.png` намеренно не публикуется.
- Программа не подписана цифровой подписью. Не обещайте отсутствие предупреждений SmartScreen или ложных срабатываний антивируса.

## 4. Создайте релиз

На GitHub откройте **Releases → Draft a new release**:

- Tag: `v1.0.0` (новый тег на опубликованном коммите).
- Title: `SCUM Volume Control 1.0.0 · HIMTGK`.
- Description: содержимое `RELEASE_NOTES.md`.
- Прикрепите `release\SCUMVolumeControl-1.0.0-windows-x64.zip` и `release\SHA256SUMS.txt`.
- Если тест на чистой Windows ещё не проведён, отметьте **Set as a pre-release**.
- Опубликуйте релиз. После этого можно делиться ссылкой на него.

GitHub автоматически добавит исходники из тега. Подготовленный source ZIP отдельно прикладывать необязательно.

## Обновление архивов

Из корня проекта в PowerShell:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\prepare_release.ps1
```

Это локальный скрипт упаковки; он не меняет пользовательские настройки и ничего не публикует.
Для новой версии обновите `version_info.txt`, README, RELEASE_NOTES и параметр `-Version` скрипта; затем пересоберите EXE.
