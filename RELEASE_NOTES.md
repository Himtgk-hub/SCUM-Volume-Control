# SCUM Volume Control 1.0.0 · HIMTGK

Первый подготовленный к публикации релиз утилиты управления громкостью SCUM для Windows.

## Возможности

- Глобальные горячие клавиши изменения громкости игры.
- Автоматическое приглушение резких пиков и постоянного шума.
- Удержание и ступенчатое приглушение повторяющихся ударов.
- Независимые выключатели горячих клавиш и автозвука.
- Русский интерфейс, работа в трее, уведомления Windows и оверлей.
- Логотип HIMTGK, ссылки автора и добровольная поддержка через Boosty.

## Установка

Скачайте `SCUMVolumeControl-1.0.0-windows-x64.zip`, распакуйте и запустите `SCUMVolumeControl.exe`.
Нужна Windows 10/11 x64; Python устанавливать не требуется.

На первом запуске автоматика выключена. По умолчанию ↑/↓ меняют ручную громкость с шагом 5 %.

## Ограничения

Это реактивное управление микшером: первый громкий звук не гарантированно приглушается. Это не средство защиты слуха.
Алгоритм не распознаёт игровые действия: выстрелы и контейнеры могут активировать удержание.
Оверлей может быть невидим в эксклюзивном полноэкранном режиме; Windows также может скрывать уведомления.
EXE не имеет цифровой подписи.

При обновлении локальные настройки сохраняются в `%APPDATA%\SCUMVolumeControl`.
