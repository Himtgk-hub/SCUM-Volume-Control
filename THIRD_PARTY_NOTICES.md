# Сторонние компоненты

Лицензия собственного кода проекта пока не выбрана. Этот документ не меняет лицензии зависимостей и не заменяет их полные тексты.

Основные компоненты:

| Компонент | Источник / лицензирование |
|---|---|
| Python | https://www.python.org/ — PSF License и включённые уведомления |
| PySide6, Shiboken6, Qt | https://www.qt.io/licensing/ — условия Qt for Python/Qt, включая LGPL/GPL/коммерческие варианты и лицензии включённых компонентов |
| pycaw | https://github.com/AndreMiras/pycaw |
| comtypes | https://github.com/enthought/comtypes |
| psutil | https://github.com/giampaolo/psutil — BSD-3-Clause |
| Vosk | https://github.com/alphacep/vosk-api — лицензия API и включённых библиотек |
| sounddevice | https://github.com/spatialaudio/python-sounddevice — MIT, также используется PortAudio |
| PyInstaller | https://pyinstaller.org/ — GPL с исключением для распространяемых сборок |

Есть также транзитивные зависимости. Скрипт `tools/prepare_release.ps1` сохраняет список установленных пакетов и найденные в их метаданных тексты лицензий в каталог `licenses` внутри бинарного ZIP. Это вспомогательный сбор, не гарантия полноты юридической проверки.

При распространении PySide6/Qt необходимо отдельно проверить соблюдение условий выбранной лицензии, включая применимые требования к уведомлениям, исходникам библиотек и возможности их замены. Однофайловая упаковка PyInstaller не освобождает от этих требований. При необходимости измените способ упаковки или получите подходящую коммерческую лицензию.

Русская модель Vosk загружается отдельно при запуске диагностики и не входит в EXE. Условия конкретной модели см. на https://alphacephei.com/vosk/models и в скачанном комплекте модели.

Логотип HIMTGK — авторский ресурс проекта, не часть сторонних библиотек.
